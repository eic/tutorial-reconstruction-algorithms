---
title: 'Learner Profiles'
---

This lesson targets ePIC collaborators who want to go beyond running reconstruction as-is and start
contributing to [EICrecon](https://github.com/eic/EICrecon) itself — typically graduate students,
postdocs, and software developers who need to apply an existing reconstruction algorithm in a new
context or add a brand-new algorithm. Learners are expected to be comfortable with C++ and to have a
working `eic-shell` environment; no prior experience with JANA2, factories, or PODIO is assumed.
